# Руководство по созданию ADR в CADR

ADR (Architecture Decision Record) — короткий документ, фиксирующий одно
архитектурное решение: что решили, почему и от чего отказались.

## Как создать
1. Откройте организацию → «Все ADR организации» → выберите папку.
2. «Создать ADR» (нужна роль Architect или Admin) → при желании выберите шаблон.
3. Заполните секции (обычно: Контекст → Решение → Последствия) и создайте.
4. Коллеги комментируют и голосуют; при достижении порога лайков ADR
   одобряется автоматически, иначе решение принимает Admin.
5. Одобренные ADR не трогаем — для пересмотра используйте связи
   «Заменяет» / «Устарел в пользу» и новый ADR.

## Как организовать дерево папок
**Первым делом создайте ADR «CHECKME»** (или «README») в корне организации —
он описывает систему в целом: назначение, основные подсистемы, где что искать.
Можно его создавать и в каждой папке, которая описывает, какие решения и какого характера
содераться в ней.
Это точка входа для новичков и агентов.

Дальше — рекомендуемая структура:

```
CHECKME
├── backend/
|   CHECKME
│   ├── api/            ← решения по HTTP-контракту
│   ├── database/       ← миграции, модели данных
│   └── messaging/
├── frontend/
|   CHECKME
│   ├── components/
│   └── state/
└── infra/
|   CHECKME
    ├── ci-cd/
    └── monitoring/
```

Способы деления подпапок (в порядке предпочтения):
1. **По бизнес-доменам (рекомендуется)** — `payments/`, `billing/`:
   лучше всего переживает рост и смену технологий.
2. **По слоям системы** — `api/`, `domain/`, `persistence/`: просто,
   но решения одного домена размазываются.
3. **По технологическому стеку** — `postgres/`, `kafka/`: удобно для
   платформенных команд, но связь с бизнесом теряется.

## Советы
- Один ADR = одно решение. «Переходим на Kafka» — да; «переходим на Kafka
  и переписываем фронт» — два ADR со связью RelatedTo.
- Пишите «почему», а не «что»: альтернативы и причины ценнее самого выбора.
- Устаревшее решение не удаляйте: статус Deprecated + связь на новый ADR
  сохраняют историю.
- Периодически выгружайте одобренные ADR (кнопка экспорта) и кладите рядом
  с кодом — это готовый контекст для AI-агента.
